Trip Bot · 出海内容生成智能体

平台：Coze 工作流 工作流 ID：travel_content_generator 状态：MVP 已搭建 · 六要素定稿 更新：2026-11-03 性质：个人独立项目

01背景与问题

问题具体表现
产出慢按“城市 × 平台”持续产出，人工单条约 30 分钟，难支撑持续分发
事实不可靠通用模型会补全不存在的 POI、地址、门票与开放时间，伤害账号信任
上下文丢失Coze 工作流默认无状态，每轮重复输入城市和平台，连续出稿体验断裂
产品定义：用 RAG 约束事实、用会话上下文延续需求，用三版钩子覆盖不同点击动机；用户记忆表当前仅写入，不参与生成。

02目标与非目标

目标（MVP）

  • 单次输出标题 + 正文 + 标签 + Tips + 三版钩子
  • 不编造地址 / 门票 / 开放时间，无法核实即标注
  • 城市/平台留空时回落默认值；连续出稿在当前会话内生效
  • Instagram / TikTok / YouTube 语感可区分

非目标

  • 自动发布到社媒
  • 图片、视频生成
  • 实时 POI 校验与商业数据接入
  • 多用户生产化（当前为演示模式）

03用户与核心场景

用户：出海内容运营 / 社媒运营，一人维护多个平台，需要稳定、可审核的文案供给。

  • S1 新城市冷启动：输入城市 + 平台，一次拿到可直接进入审核的文案包。
  • S2 连续出稿：只说“再来一条”，在当前会话内沿用上次城市与平台；开启新对话后回落默认值。
  • S3 平台改写：说“换成 TikTok”，保留城市，切换平台语感与钩子。

04核心流程

01开始输入 city / platform，均可留空
02查询记忆读取 user_memory（当前仅保留链路）
03联网搜索按城市补充实时信息
04JS 合并本次 > 默认值（历史不参与）
05RAG 检索爆款写法与平台范式，Top-K 3–5
06正文生成LLM A 按平台语感写作
07钩子优化LLM B 输出三版钩子
08写回记忆upsert 本次城市与平台
09结构化输出参数 / 正文 / 钩子 / 来源

读写依赖：② 与 ⑧ 共用 user_memory；⑤ 读取知识库《旅行文案的全套心法》；③ 调用 Coze 联网搜索获取景点信息，输出需人工核实。

05功能需求 · 六要素（城市输入框）

要素规格（2026-11-02 实测口径）
位置底部输入区（开启新对话 / 输入框 / 加号 / 语音，均平台自带不可改），上方历史消息区、下方免责声明；开启新对话时有分隔线。
交互输入文字后才出现 ➤，空输入不可发；城市与平台可只给其一；「再来一条」为文字指令；生成后可复制 / 重新生成 / 删除。
状态等待（调用提示）→ 完成（三版钩子 / 标题 / 正文 / 标签）；追问三类话术各不相同；断网提示超时；思考外露属缺陷。
来源本次输入 → 默认值 清迈 / Instagram（写在代码节点内，画布不可见）；user_memory 只写不读；图片不产生 city。
逻辑本次输入 || 默认值；只给城市→平台默认 Instagram；只给平台→城市沿用会话；新对话→回落默认。白名单在 Agent 人设层，工作流不归一化，ins 原样进检索词。
极值空消息不可发；空格 / emoji / 两类乱码各有兜底；20 / 500 字规则未落地校验；连点 3 次只回 1 条；600 字下约束失效。

06记忆规则

final_city = 本次 city || "清迈" final_platform = 本次 platform || "Instagram"

写回字段：user_id、city、platform 三个；表中另有 style / emoji / last_hook / updated_at，当前恒为空（表结构先于功能落地）。

读取策略：B 方案——历史记忆只写不读，清除上下文即当新用户；表内数据作为后续个性化预留。连续出稿依赖平台自带的会话上下文，而非数据表。

当前 user_id 固定为 my_trip_bot + 单用户模式，所有使用者共用同一份数据。生产环境需替换为会话 ID 或登录态 user_id。

07生成约束

平台语感硬约束
Instagram松弛、光影、生活方式emoji ≤ 3
TikTok前 3 秒反差/悬念，短句正文 ≤ 80 字
YouTube信息密度高，实用 Tips含 Tips 区

共同约束：禁止编造地址/门票/开放时间；金额与开放时间无法核实须标注「待核实」；输出标题 + 正文 + 标签 + Tips；钩子 ≤20 字并标注风格。

08边界处理

场景处理方式
城市与平台均为空回落默认值 清迈 / Instagram（工作流层），Agent 层另有追问话术
平台为空默认 Instagram
事实无可靠来源不编造，写「待核实」或跳过具体金额/时间
平台不在白名单只提示支持 IG / TikTok / YouTube，不生成文案
中途换平台更新平台，保留城市
乱码 / 无意义输入两类话术：无意义文字→追问城市与平台；含符号乱码→提示无法识别并引导重输
模型串平台语感钩子标注平台，由人工选择

09评测与验收

维度判定标准
记忆命中空输入时城市/平台与上次一致
事实可靠POI 真实；不编造地址 / 门票 / 开放时间
平台适配三种平台语气明显区分
钩子质量三版风格不同，至少一版想点开
兜底健壮乱输入不崩，有引导话术

用例：20 条已设计 = 正常 3 + 边界 7 + 对抗 5 + 质量 5；已执行 10 条，修复后复测 5 条通过；剩余 10 条不执行，作为已知局限。

验收：无编造地址 / 门票 / 开放时间（以评测记录为准）；空输入回落默认值；乱输入 0 崩溃；单次生成 57–97 秒（2 次样本）。

10指标

北极星：单次生成中可直接进入人工审核的文案包比例。

过程：生成时长、编造率、记忆命中率、钩子可用率、badcase 率。

数据现状：尚未实测。先完成 20 条用例并记录 badcase，再对外引用任何提升数字。
